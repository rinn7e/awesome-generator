# Awesome Generator

> CLI tool to generate lint-compliant [Awesome](https://github.com/sindresorhus/awesome) curated list Markdown files from any input JSON file with runtime `io-ts` schema validation.

---

## Overview

`awesome-generator` accepts an input path to a JSON dataset file, validates its structure against [`io-ts`](https://github.com/gcanti/io-ts) type schemas, and formats the output into a self-contained, [`sindresorhus/awesome-lint`](https://github.com/sindresorhus/awesome-lint)-compliant `README.md`.

It also includes an integrated **Nix-style source crawler and auditor** (`npm run crawl`) to check HTTP reachability and extract update timestamps.

---

## Key Features

- **Decoupled CLI Architecture**: Pass explicit input JSON file path and output Markdown file path anywhere on disk.
- **`io-ts` Runtime Schema Validation**: Strictly validates input JSON schema before generating Markdown.
- **Awesome-Lint Compliant**: Automatic badge headers, slugified Table of Contents (`## Contents`), and standardized list formatting (`- [Title](URL) *(Jul 2026)* - Description.`).
- **Nix-Style Store Crawler Cache**: Content-addressed SHA-256 caching for link auditing (`scripts/crawler/cache/`).
- **Human-Readable Timestamps**: Formats entry update dates into subtle month-year tags (e.g. `*(Jul 2026)*`).

---

## Dataset Sorting Strategy

`awesome-generator` strictly respects and follows the exact section and item order defined in the input JSON dataset file. It does not forcefully mutate or re-order your data during Markdown rendering.

When authoring JSON datasets, follow these recommended sorting guidelines:

- **Sections (Categories)**: Sort sections logically from **General / Common** resources first down to **Specific / Specialized** resources.
- **Entries (Items)**: Sort items within each section **Alphabetically** by title (A to Z).

## CLI Usage

### Generate Markdown

Pass the path to your input JSON file and desired output Markdown file:

```bash
# Using CLI options
pnpm run generate -- --input /path/to/input.json --output /path/to/README.md

# Using positional arguments
pnpm ts-node src/index.ts /path/to/input.json /path/to/README.md
```

#### Real-World Example:
```bash
pnpm run generate -- \
  --input ../awesome-list/awesome-cambodia-jobs/cambodia-jobs.json \
  --output ../awesome-list/awesome-cambodia-jobs/README.md
```

---

### Audit & Crawl Sources

Pass the path to your input JSON file to verify URL health and update timestamps:

```bash
# Audit sources with Nix-store cache
pnpm run crawl -- --input /path/to/input.json

# Force bypass cache and audit live
pnpm run crawl -- --input /path/to/input.json --force
```

#### Facebook Link Audit Rule

Basic static HTTP `fetch()` is **strictly prohibited** for Facebook-related links (`facebook.com` / `fb.com`). Because Facebook renders page content dynamically via React/GraphQL client-side, the crawler launches a headless **Playwright Chromium browser** to render the DOM text content directly and verify that the page is publicly accessible and does not display an unavailable error message.

```bash
# Audit sources with Nix-store cache (24h TTL)
pnpm run crawl -- --input /path/to/input.json

# Bypass cache and force re-crawl all URLs
pnpm run crawl -- --input /path/to/input.json --force
```

#### Real-World Example:
```bash
pnpm run crawl -- \
  --input ../awesome-list/awesome-cambodia-jobs/cambodia-jobs.json
```

## Input JSON Schema

Your input `.json` file must conform to the `AwesomeList` `io-ts` schema:

```json
{
  "slug": "awesome-cambodia-jobs",
  "title": "Cambodia Jobs",
  "description": "A curated list of awesome job portals in Cambodia.",
  "sections": [
    {
      "title": "Job Portals",
      "description": "Primary job boards operating in Cambodia.",
      "items": [
        {
          "title": "BongThom",
          "url": "https://www.bongthom.com",
          "description": "Leading job portal in Cambodia",
          "lastUpdated": "2026-07"
        }
      ]
    }
  ]
}
```

## Awesome Lists Generated by Awesome Generator

Every curated list generated by `awesome-generator` fulfills specific human needs from **Maslow's Hierarchy of Needs**:

- Repositories provide actionable resources for specific layers of human survival or growth.
- Multiple lists can fulfill the same core need across different regions or domains (e.g., `[Employment]` via Cambodia Jobs, Singapore Jobs).
- Prioritizes foundational safety needs (shelter, jobs, health, legal rights) before higher-level needs.
- Direct links to verified portals, active channels, and public institutions.
